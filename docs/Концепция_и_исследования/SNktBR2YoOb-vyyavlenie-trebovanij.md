# Выявление требований

#### Кодировка болей

- Б1 - ручной перенос данных, лаги таблицы
- Б2 - несопоставимость из-за железа, ОС, способов замера
- Б3 - недоверие к чужим результатам
- Б4 - зависимость от старосты
- Б5 - нет единого формата ввода-вывода
- Б6 - непонятно, где я на фоне группы.
- Б7 - есть желание прогрессировать, но нет инструментов

#### User Story

Формат: «Как <роль>, я хочу <действие>, чтобы <ценность>».
